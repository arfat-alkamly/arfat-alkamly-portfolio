# Public certificates

Upload original certificate PDFs to this folder.

## Important
Files uploaded here are intended to be public and may be displayed on the portfolio website. Do not upload certificates containing private information you do not want published.

Use clear filenames, for example:
- cisco-endpoint-security.pdf
- it-customer-support-basics.pdf

After uploading, submit the changes on the `public-certificates-upload` branch. They will be reviewed and added to the portfolio through a pull request.
