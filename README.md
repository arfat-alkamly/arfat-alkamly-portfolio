# ARFAT ALKAMALI — Professional Portfolio

A bilingual (English / Arabic) professional portfolio for Arfat Abdullah Hussein Al-Kamly, focused on cybersecurity, networks, software development, and technical research.

## Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Import this repository into Vercel and select the **Next.js** framework preset. Keep the root directory as `.`.

## Content accuracy
Project stages and skill descriptions are intentionally conservative. Add verified certificates, a public CV, and a preferred contact email before presenting them as confirmed credentials.
